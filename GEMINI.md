# Workspace Rules & Project Notes

## Typography Constraints

> [!IMPORTANT]
> **Petit Formal Script (Pettit Format) is permanently banned.**
> Never import, reference, or use `Petit Formal Script` (or any variation of it) anywhere in this repository (HTML, CSS, JS, or documentation).

### Approved Font Hierarchy
- **H1 & Primary Serif**: `'Gambetta'`, `'Newsreader'`, `'Times New Roman'`, Georgia, serif
- **H2 & Body Text**: `'Outfit'`, -apple-system, BlinkMacSystemFont, sans-serif
- **H3 & Editorial Accents**: `'Newsreader'`, `'Times New Roman'`, Georgia, serif (use `font-style: italic` for flourishes)
- **Monospace / Data**: `'Outfit'`, monospace

### Font Asset & Import Rules
- `Petit Formal Script` font files have been completely deleted from `assets/fonts/`.
- Do not re-add Google Font URLs or `@font-face` definitions for `Petit Formal Script`.
- Ensure all heading and UI tokens exclusively reference `Gambetta`, `Outfit`, or `Newsreader`.
